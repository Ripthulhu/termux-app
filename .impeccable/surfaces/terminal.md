# Terminal screen

Mode: Operate

The primary task is reading and interacting with a terminal, frequently Codex CLI. Sessions and recovery actions must be discoverable without occupying the terminal's screen edges. The terminal remains the main content.

Use Material 3 color roles, typography and native components. Compact windows use an explicit modal Sessions panel; windows at least 840dp wide show that same panel beside the terminal. Keys keep their touch targets and scroll horizontally when the window is too narrow. Keep saved terminal input, custom layouts, shell sessions, PiP and bubble behavior working across resize and theme changes.

Verify phone light/dark themes, large text, narrow windows, expanded layout and return to compact; check system Back and keyboard focus. Screenshots must come from Android, with emulator fixtures identified as demonstrations.
